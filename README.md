# 🏥 Hospital Patient Care Operations Analytics | MySQL

## 📌 Project Overview
Hospital Patient Care Operations Analytics is a SQL-based data analytics project focused on understanding hospital operations, patient appointment patterns, treatment outcomes, doctor performance, and resource utilization.

The project uses MySQL to analyze five interconnected tables: Patients, Doctors, Rooms, Appointments, and Treatments, generating actionable business insights to support data-driven decision-making.

## 🎯 Business Objectives
- Analyze appointment demand and estimated value.
- Identify repeat patients and high-value patients.
- Evaluate treatment performance and patient outcomes.
- Analyze doctor workload and performance.
- Examine room utilization and maintenance.
- Identify cancellations, no-shows, and rescheduled treatments.

## 🛠️ Tools & Technologies

- MySQL Workbench
- SQL

## 📊 SQL Concepts Used
- SELECT, WHERE, ORDER BY
- GROUP BY and HAVING
- INNER JOIN and LEFT JOIN
- Aggregate Functions
- Subqueries
- CASE Statements
- Date Functions

## 🔍 Key Insights
- Analyzed 3,000 appointments across 8 cities.
- Evaluated 3,500 treatment records.
- 70.4% of treatments were completed.
- Identified 534 cancelled and no-show treatment records.
- Identified high-workload doctors and heavily utilized rooms.
- Highlighted overdue room maintenance.

## 💡 Business Recommendations
- Improve appointment scheduling and patient reminders.
- Optimize doctor workload distribution.
- Reduce cancellations and no-shows.
- Improve room maintenance planning.
- Prioritize urgent patient appointments.
